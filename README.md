# Simulated Job Board ATS Integration

This example demonstrates how multiple distinct job board front-ends can utilize a single, shared Applicant Tracking System (ATS) backend. It simulates two different job board brands processing applications through the same underlying ATS logic, illustrating the hidden integrations common in the recruitment technology landscape.

## Language

`html`

## How to Run

Save the code as `index.html`.
Open `index.html` in any web browser.
